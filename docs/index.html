启动方式

推荐 Python 3.12。Windows 双击“启动检索.bat”；macOS 双击“启动检索.command”。首次联网安装依赖，后续本地浏览器使用。也可手动建立 .venv，安装 requirements.txt，再运行 run.py。

发现与修复

问题处理
Python 新版本无法安装将旧 OCR 依赖限定到其支持的 Python 版本，Python 3.13+ 保留文本文档功能；提供项目内虚拟环境启动脚本。
长 PDF 页面漏检原来超过 6000 字即截断，改为完整分块，保留同一页定位。
Excel 公式单元格消失当工作簿有普通表头但公式没有缓存值时，保留“未计算公式”文本，不虚构运算结果。
索引线程退出竞态保持工作线程并在锁内更新状态，避免任务恰好入队时无人处理。
配置与本机接口保护不足密钥移入 local-secrets，GET/POST 设置均不回传真实密钥；留空保留，显式勾选移除。校验 Host、Origin、参数和配置结构。
原生窗口失败后无法启动复用已启动的服务器切换到浏览器，避免重复绑定端口。
部分扫描页失败不可见体检报告显示每页 OCR 错误。损坏配置留档并完整回退默认值，打包工具排除凭据。

  • Chrome：设置页保存/留空保留/移除密钥、问答和桌面/手机视口无脚本错误；--window 无组件降级复用服务通过。
