# EveryFind · 本地文档内容检索工具

> 直接问资料，答案有出处。
> 索引、检索和 OCR 在本机运行；启用云端模型时会发送问题与命中文档片段。

给 Word / Excel / PPT / PDF / 图片 / 文本做**全文索引 + 问答 + 溯源**的桌面工具。
你可以像聊天一样提问，它从你的本地文件里找出答案，并且每条结论都标着出处编号，
点一下就能回到原文的**段落 / 页码 / 工作表行号 / 单元格坐标 / 幻灯片页码**核对。

---

## 一、它能做什么

| 能力 | 说明 |
|---|---|
| 📄 全格式内容索引 | `.docx` `.xlsx` `.pptx` `.pdf` `.jpg/.png` `.txt` `.md` `.csv` `.json` …，旧版 `.doc/.xls/.ppt` 在装有 Office 的机器上自动转换 |
| 💬 自然语言问答 | 并列提问会自动拆成子项逐条作答；问「多少/几天/谁负责」会识别答案类型 |
| 🔍 全文搜索 | 中文分词 + 字符二元组混合召回，命中处高亮；限定范围后同步收窄 |
| 🔗 引用溯源 | 每条答案带 `[1]` 编号，点开即见原文摘录与精确定位 |
| 📊 表格定位到单元格 | Excel 命中后给到 `工作表 · 第 4 行 · 单元格 B4` |
| 🖼 图片 / 扫描件 OCR | 本地 RapidOCR（CPU、离线）识别图片与扫描 PDF 里的文字 |
| 📥 拖拽导入 | 文件 / 文件夹直接拖进窗口即导入，保留原目录结构 |
| 💬 多轮追问 | 「那预算是多少？」这种省略句，会自动结合上文一起检索 |
| 🧮 表格聚合计算 | 「预算合计是多少？」直接按表里的原始数值算，给出算式与出处 |
| 🎯 限定范围问答 | 点资料库里的某个文件或目录，接下来只在这里找答案 |
| 🗂 目录感知 | 资料按目录分组显示，同名文件不会再分不清 |
| 🩺 索引体检报告 | 一键体检：哪些文件解析失败、哪些待索引、OCR 和同步是否正常 |
| 📤 导出问答 | 答案一键导出 Markdown / Word，末尾附「引用出处」清单 |
| 🕘 问答历史 | 问过的问题自动存档，重启不丢，可回看、再问、导出 |
| 🔒 完全本地 | 资料永不上传；即使接云端模型，也只发送「问题 + 检索到的片段」 |

## 二、快速开始

### 1. 安装依赖

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```

推荐 Python 3.12，以使用本地 OCR。Python 3.13+ 可以运行文本文档检索，但本版 OCR 依赖不支持，会自动跳过安装。Windows 可双击 `启动检索.bat`；macOS 可双击 `启动检索.command`。首次安装需要联网。详见 [修复说明](docs/index.html)。

### 2. 启动

```powershell
.venv\Scripts\python run.py
```

浏览器会自动打开 `http://127.0.0.1:8765`。

常用参数：

```powershell
python run.py --port 9000      # 换端口
python run.py --no-browser     # 不自动开浏览器
python run.py --window         # 用原生窗口打开（需 pip install pywebview）
python run.py --rebuild        # 清空索引库重建
```

### 3. 添加资料

左侧四个入口：

1. **添加文件夹**（推荐）— 把常用资料丢进去，新文件和修改会自动更新
2. **选择文件** — 只用几份资料时最省事
3. **拖拽上传** — 从资源管理器直接把文件/文件夹拖进窗口就完成导入
4. **扫描磁盘** — 不确定文件在哪就整盘找（范围大，首次耗时较久）

首次建索引需要时间，底部进度条会显示当前状态。

左侧「资料库」区右上角有四个小按钮：**刷新**（重扫已添加的文件夹）、**重建**（全部重新索引）、
**体检**（打开索引体检报告，见 4.6）、**历史**（查看问过的所有问题，见 4.9）。

**自动同步**：添加文件夹后，工具每隔 60 秒自动重扫一次，新文件、修改过的文件会自动入库，
从磁盘删掉的文件会自动从索引移除。整盘扫描因为要遍历整块盘，默认 30 分钟一次。
间隔可在「设置 → 资料库自动同步间隔」里改，填 `0` 关闭自动同步（此时只能手动点左侧「刷新」）。

### 3.5 拖拽上传

从资源管理器里**直接把文件或整个文件夹拖进工具窗口**，松手即导入：

- 拖到窗口任意位置都会出现「松手即可导入」提示层
- **拖文件夹会保留目录结构**，例如拖入 `项目A/2026/预算.xlsx`，落盘后仍是 `项目A/2026/预算.xlsx`
- 一次最多批量 20 个文件一批提交，文件多也不会卡住
- 侧边栏底部有**导入进度条**，大批量时能看到走到哪儿了
- 不支持的格式（如 `.exe`）会被自动过滤，不会入库
- 同名文件不会互相覆盖，自动改名为 `xxx(1).xxx`
- 某个文件没传成功时，底部会列出失败清单，**可以只重试失败的那几个**，不用整批重来

**拖拽上传 vs 其它入口，差别在哪：**

| | 添加文件夹 | 拖拽上传 | 选择文件 |
|---|---|---|---|
| 资料放在哪 | 你指定的原目录 | **复制一份**到 `data/uploads/` | 引用你选的原文件 |
| 原文件改了 | 自动同步更新 | 不影响（副本不动） | 自动更新 |
| 目录结构 | 原样保留 | 原样保留 | 平铺 |
| 适合 | 长期资料库 | 一次性导入、临时分享过来的文件 | 零散几份 |

> **复制副本**：浏览器出于安全限制拿不到你文件的真实磁盘路径，只能读到文件内容，
> 所以拖进来的东西会被**复制**到 `data/uploads/`（和 `index.db` 放在一起）。**原始文件完全不受影响**，
> 删掉副本也不会删到你的原文件。
>
> 想让资料长期跟着原文件走，请用「添加文件夹」。

副本放在 `data/uploads/`，可以直接用文件管理器打开、手动整理、或删掉。
删掉副本后，索引会在下次自动同步时（默认 60 秒内）把它一并清除，搜不到也不会再出现在资料列表里。

### 4. 开始提问

- 「**问答**」标签：像聊天一样提问，答案带 `[1]` 引用
- 「**全文搜索**」标签：关键词检索，命中处高亮

**可以接着问。** 第一句问完，直接追问「那预算是多少？」「谁负责的？」这种省略句，
工具会自动把上文的关键词带进来一起检索，回答下方会标注「已结合上文扩展检索」。
（上下文保留最近 8 轮，实际检索时用最近 3 轮。）

### 4.5 限定检索范围

想只在一份文件、或某一个目录里找答案，有三种方式：

| 方式 | 操作 |
|---|---|
| **点文件名** | 左侧资料库列表里点一下文件，顶部立刻出现「检索范围」条 |
| **点目录标题** | 左侧资料库列表里点目录名，范围条变成这个目录（含它下面的子目录） |
| **限定到某个文件** | 输入框上方范围条里的按钮，弹文件选择器挑一份 |

限定之后：

- 提问只在这份文件 / 这个目录里检索，答案不会串到别的资料；侧边栏仍可随时再点别的文件切换。
- **全文搜索也一起收窄** —— 切到「全文搜索」标签，搜索结果同样只在这个范围内，
  搜索框上方同样会显示范围条，随时可以点 ✕ 取消。
- 点范围条上的 **✕** 取消限定，恢复全库检索。

### 4.6 索引体检报告

左侧「资料库」右上角的 **体检** 按钮，打开的是一份索引体检报告：

| 板块 | 内容 |
|---|---|
| 统计块 | 资料总数 / 索引成功 / 解析失败 / 已跳过 / 待索引 / 内容块 |
| 按格式分布 | 每种格式的文件数、内容块数、失败数 |
| 问题清单 | 逐条列出出问题的文件：解析异常、格式不支持、内容为空 |
| 需要留意 | OCR 不可用、自动同步已关闭、还没填 API Key 等环境提醒 |

体检不修改任何数据，只做诊断 —— 排查「为什么搜不到」「为什么这个文件没结果」时先看它。

### 4.7 导出答案

每条回答下方有两个按钮：

- **导出 Markdown** —— 纯文本，适合贴进 Obsidian / 飞书 / GitHub
- **导出 Word** —— 带样式的 `.docx`，可直接当交差材料

两种格式末尾都会自动附上「**引用出处**」清单（文件名 + 精确位置 + 原文片段），
导出来的东西自带出处，不用再回头翻。

### 4.8 表格聚合计算

问「**预算合计是多少？**」「**一共有多少个预算项目？**」「**实际支出最多的是哪一项？**」
这类问题时，工具会直接**按表里的原始数值算**，不靠模型转述：

```
「预算」在 2 个文件里都有，以下按文件分别列出（不跨文件相加）：
2026/年度预算.xlsx　预算合计：390,000（5 项相加） [1][2]
年度预算.xlsx　预算合计：248,000（4 项相加） [3]
```

几条硬规矩，都是为了不让数字错：

| 规则 | 为什么 |
|---|---|
| **「合计」行不参与计算** | 表里那行本来就是所有分项的和，再加一次就双倍了 |
| **不跨文件相加** | 不同文件里的「预算」不是同一笔钱，副本会被算两遍 |
| **不跨单位相加** | 「预算（元）」和「预算（万元）」是两个口径，凑一起加毫无意义 —— 会分开列出 |
| **同一文件的多个工作表会一起算** | 例：`2026预算` 和 `2025预算` 两张表的行都参与，「N 项相加」里的 N 会告诉你加了几行，引用里也能看到具体是哪几行 |
| **只认唯一确定的列** | 问题里点名的列、或整张表只有一个数值列时才动手 |
| **算不出就不算** | 拿不准时照常走检索，绝不硬凑一个数字 |
| **聚合意图只看本轮提问** | 上一轮问过「最大值」，这一轮问「最小呢」，不会被上一轮带跑 |

「合计」行的识别覆盖了实际表格里的各种写法：`合计`、`合计：`、`共计`、`本年合计`、
`合 计`、`合计（万元）`、`Total`、`小计`。

结果里带 `[n]` 引用编号，点开能回到具体是哪一行、哪个单元格。

### 4.9 问答历史

左侧「资料库」区右上角有「**历史**」按钮，点开是问过的所有问题：

- **自动存档**：服务端在每次提问后自动记，页面崩了、刷新了都不会丢
- **再问一次**：点「再问一次」把问题重新填进输入框
- **点问题**：直接填进输入框，改一改再问
- **删除 / 清空**：单条删或全部清
- **导出 Markdown**：把整份问答记录导出成一份文档

重启工具后，最近几轮会自动灌进追问上下文，接着问也能接上。

### 4.10 目录感知

资料按**相对目录**分组显示（`2026/预算/` 这样），不再是一长串平铺的文件名。
同名文件在不同目录里也能分清。

点目录标题就能把检索范围**限定到这个目录**（含它下面的所有子目录），接着问只在这个目录里检索；
再点一次取消。限定范围也支持文件级（点文件名）和目录级（点目录标题）两种。

### 5. 怎么问效果最好

| 问法 | 例子 | 效果 |
|---|---|---|
| 直接问事实 | `差旅费预算是多少？` | 最稳 |
| **带文件名** | `年度预算.xlsx 里差旅费预算是多少？` | 命中率最高，能排除同名干扰 |
| **并列提问** | `验收报告、操作手册、问题清单分别由谁负责？` | 会自动拆成子问题逐条作答 |
| 带字段名 | `云舟项目方案.pptx 里第三阶段是什么计划？` | 配合文件内定位更准 |
| **追问省略句** | 先问 `差旅费预算是多少？`，再问 `那预算是多少？` | 自动结合上文扩展检索 |

问「多少 / 几天 / 几周 / 谁负责 / 什么时候」时，工具会识别答案类型，优先挑出带数字、责任人或日期的句子。

### 6. 怎么核对答案

- 答案里的 **`[1]` `[2]`** 是绿色小徽章，点它直接跳到来源面板
- 来源面板给的是**原文片段 + 命中高亮**，不是摘要，可以逐字核对
- Excel 命中会额外给一张「位置 / 字段 / 原值」表，并高亮具体单元格（如 `C4 = 32000`）
- PPT 给到「第 N 张幻灯片 + 幻灯片标题」，Word 给到「第 N 段 + 标题层级」，PDF 给到「第 N 页」
- 面板底部两个按钮：**打开文件**（用 Office 打开原件）、**在文件夹中显示**（定位到磁盘上的真实位置）
- 「▶ 查看依据 · N 个文件」展开后可以逐条看所有引用

答案末尾如果标着「**未接入模型，以上为资料原文摘录**」，说明当前是纯本地检索模式；
标「**模型生成 · 已标注引用来源**」则是接了大模型后由模型组织的答案。
如果模型调用失败，会明确写成「**模型调用失败 · 已降级为原文摘录**」并附上接口报错原文 ——
不会拿摘录冒充成模型答案。

## 三、接入模型（可选）

**不接模型也能用**：工具会用「原文摘录模式」——直接从资料里挑出最相关的原句给你，
界面会明确标注「未接入模型」。

接入模型后，工具会把检索到的片段交给模型，让它**组织成一段完整的答案**并标注引用。

界面右上角「设置」里可填：

| 方式 | Base URL | 模型 | 备注 |
|---|---|---|---|
| OpenAI 兼容 | `https://api.deepseek.com/v1` | `deepseek-chat` | 也支持通义、智谱、Moonshot、Kimi |
| 本地 vLLM / LM Studio | `http://127.0.0.1:8000/v1` | 本地模型名 | 全离线，推荐 llama3 / qwen 系列 |
| Ollama 原生 | `http://127.0.0.1:11434` | `qwen2.5:7b` | 需先 `ollama pull` |

填完点「测试连接」确认通，再点「保存设置」。

### 以 DeepSeek 为例（4 步）

1. 到 [platform.deepseek.com](https://platform.deepseek.com) 注册，充值/领赠额后创建 API Key（`sk-` 开头）。
2. 打开工具右上角「**设置**」。
3. 四个字段照抄：

   | 界面字段 | 填什么 |
   |---|---|
   | 接入模型 | `OpenAI 兼容接口（含本地 vLLM / LM Studio / Ollama 的 /v1）` |
   | 接口地址 Base URL | `https://api.deepseek.com/v1` |
   | API Key | 你的 `sk-...` |
   | 模型名称 | `deepseek-chat`（要推理链就填 `deepseek-reasoner`） |

4. 点「**测试连接**」→ 显示 `✓ 连接正常` → 再点「**保存设置**」。
   顶栏徽章会从「未接入模型」变成「模型：deepseek-chat」，答案卡底部标注「模型生成 · 已标注引用来源」。

其余参数保持默认即可：温度 `0.1`（要稳定复现，别调高）、引用片段数 `8`（送进模型的段落数，越大越准也越贵）。

> **片段数怎么算**：设 `top_k = 8`，实际送进模型的片段数 = `max(8, 子问题数)`，再被
> `retrieve.max_context_chunks`（默认 `16`）封顶。并列提问时，每个子问题的最佳片段会**优先**保留，
> 保证「A、B、C 分别由谁负责」这类问题每一项都有代表，不会因为截断少答一项。

> 注意：「测试连接」会先保存再测，所以它同时完成了两件事。
> 若选了「OpenAI 兼容」但 Key 填错，提问时仍会退回「原文摘录模式」，并在末尾附上接口报错原文，不会静默给错答案。

### 其它可换的模型

只要服务兼容 OpenAI 的 `/chat/completions`，直接换 Base URL 和模型名就行：

| 服务 | Base URL | 模型 |
|---|---|---|
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` / `deepseek-reasoner` |
| 月之暗面 Kimi | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` 等 |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash` 等 |
| 阿里通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` 等 |
| 本地 vLLM / LM Studio | `http://127.0.0.1:8000/v1` | 本地模型名 |
| Ollama（走 OpenAI 兼容口） | `http://127.0.0.1:11434/v1` | `qwen2.5:7b` |

> 隐私：原始文档不会发给模型，只有命中的片段 + 你的问题会离开本机。
>
> API Key 独立保存在 `local-secrets/api-keys/llm.json`，配置接口不返回真实值。旧版配置中的 Key 会在下次保存设置时迁移。设置页留空保持原 Key，勾选“移除”才清除。不要分享 `local-secrets/` 或个人数据目录。使用 `EVERYFIND_DATA` 时，凭据目录位于其父目录下。

## 四、目录结构

```
本地文档内容检索工具/
├── everyfind/                 # 后端
│   ├── config.py              # 配置读写（data/config.json）
│   ├── db.py                  # SQLite 索引库（文件表 / 内容块表 / FTS5）
│   ├── textutil.py            # 中文分词、二元组、句子切分、高亮定位
│   ├── ocr.py                 # 本地 OCR 封装（RapidOCR / ONNX）
│   ├── legacy.py              # 旧版 Office 格式（COM 转换）
│   ├── parsers/               # 各格式解析器
│   │   ├── docx_parser.py     # 段落 / 表格行 / 页眉页脚
│   │   ├── xlsx_parser.py     # 工作表 / 行号 / 单元格坐标（自动识别表头）
│   │   ├── pptx_parser.py     # 幻灯片 / 标题 / 备注
│   │   ├── pdf_parser.py      # 页码 / 表格，扫描页转 OCR
│   │   ├── image_parser.py    # 图片 OCR
│   │   └── text_parser.py     # 纯文本按行切块
```

## 五、工作原理

**索引阶段**

1. 解析文件 → 切成「内容块」，每块带结构化定位（段落号 / 页码 / 工作表行 / 单元格 / 幻灯片号）
2. 每块写两套 FTS5 索引：jieba 分词（语义召回）+ 字符二元组（中文子串召回）
3. Excel 自动识别表头，把「字段名：值」写进块文本 —— 这样问「差旅费预算是多少」能命中数值

**检索阶段**

三路加权：分词 BM25 + 二元组 BM25 + 查询覆盖率重排，再对文件名做加权。
限定范围时，文件与目录过滤会**下推到 SQL**（`JOIN chunks ON chunks.file_id = ?`、
`files.rel_dir = ? OR files.rel_dir LIKE ?/ %`），而不是先取全局结果再筛 ——
否则目标文件没进候选池就会被误判成「搜不到」。

> 目录过滤要同时匹配**目录本身**和它的子目录：直接放在 `2026/` 里的文件，
> 相对目录值恰好等于 `2026`（不带尾斜杠），只写 `LIKE '2026/%'` 会把它们全漏掉。

**问答阶段**

1. 问题拆解：并列项（「A、B、C分别由谁负责」）→ 逐项检索；多问句 → 合并检索
2. 追问扩展：省略句（「那预算是多少」）自动并入上文问题做检索扩展
3. 表格聚合：识别到「合计 / 共多少个 / 最大」这类意图且能唯一定位数值列时，
   直接按表里的原始数值算（排除「合计」行、不跨文件相加），不经过模型
4. 句子打分：二元组覆盖率 + 新颖度（有没有带来新信息）+ 答案类型加分（问数字/问人/问时间）
5. 上下文预算：`max(top_k, 子问题数)` 个片段，再按 `max_context_chunks` 封顶；
   **每个子问题的最佳片段优先入上下文**，保证并列作答不缺项
6. 有模型则交给模型组织答案并标注引用；没有模型则直接给出最贴切的原句；
   模型调用失败会明确标注「已降级为原文摘录」并附上报错原文
7. 引用编号与原文位置一一对应，点开就是原文摘录 + 高亮
   （每条回答各自记住自己的引用表，点旧回答的引用不会张冠李戴）
8. 每轮问答自动落库到本地历史，重启不丢

```powershell
.venv\Scripts\python -m pip install pyinstaller
.venv\Scripts\python tools\build.py
```

产物在 `dist/`：

- Windows：`dist/EveryFind/EveryFind.exe`（免安装目录版）

想再瘦一点，可以把 `opencv-python` 换成 `opencv-python-headless`（约省 90 MB）：

```powershell
python -m pip uninstall -y opencv-python
python -m pip install opencv-python-headless
python tools\build.py
```

> 打包版若要支持旧版 `.doc/.xls/.ppt`，目标机器需安装 Microsoft Office。

## 七、常见问题

**Q：新增/修改的文件什么时候能看到？**
添加的是**文件夹**时，默认 60 秒内自动入库；改「设置 → 资料库自动同步间隔」可以调整，
填 `0` 则关闭自动同步、只能手动点左侧「刷新」。
用「选择文件」或「扫描磁盘」加入的单个文件是立即入库的，
**「拖拽上传」也是立即入库**（松手后就开始建索引）。

**Q：拖拽上传的文件放哪了？会不会动我的原文件？**
副本在 `data/uploads/`（和 `index.db` 同一个目录），**原文件不会被复制走也不会被修改**。
你可以直接去那个目录整理或删除副本；删掉后索引会在下次自动同步时自动清掉。

**Q：拖进来一个文件夹，里面有几万个子文件行不行？**
可以，目录结构会原样保留。文件多时首次建索引需要点时间，进度在底部状态栏。
只支持文本类格式（Word / Excel / PPT / PDF / 图片 / 文本 / 代码等），
`.exe` 之类的可执行文件会被自动过滤掉。

**Q：索引很慢？**
首次索引要解析所有文件，PDF 和图片会走 OCR，属于正常。后续只索引变更过的文件。
可在「设置」里关闭 OCR 来提速（代价是图片和扫描件搜不到字）。

**Q：回答不准 / 答非所问？**
- 先确认文件已索引（左侧列表显示「N 块」）
- 点左侧「**体检**」看有没有解析失败的文件 —— 失败的文件是搜不到内容的
- 接入模型后效果会明显提升
- 提问时带上文件名或更具体的字段名，例如「年度预算.xlsx 里差旅费预算是多少」
- 或者先**限定范围**（点左侧文件名）再问，排除同名文件的干扰

**Q：追问「那预算是多少？」为什么搜不到？**
省略句会自动带上上文一起检索。如果上文本身也没查到，先把第一句问完整，
或者直接点左侧文件名限定范围再追问。

**Q：导出的答案能直接交差吗？**
可以。导出的 Markdown / Word 末尾都附了「引用出处」清单（文件名 + 精确位置 + 原文片段），
出处是可核对的，不是编的。

**Q：「预算合计是多少？」算出来的数对吗？**
它直接按表里的原始数值算，**「合计」那一行会被排除**（不然就双倍计数了）。
如果好几个文件里都有「预算」这一列，会按文件分别列出而**不跨文件相加** ——
不同文件里的预算不是同一笔钱。想只看某一个，在问题里点名文件或先限定范围。

**Q：上次问的问题还在吗？**
在。左侧「历史」按钮里能看到全部问答记录，自动存本地，重启不丢。

**Q：限定到目录之后，搜索也变少了？**
是故意的。限定范围对提问和全文搜索同时生效 —— 避免出现「已经限定到某个目录，
搜索结果却全是外面文件」这种自相矛盾。搜索框上方会显示当前范围，点 ✕ 即可恢复全库。

**Q：资料会不会上传？**
不会。索引、检索、OCR 全部在本机完成。只有你主动配置了云端模型时，
「问题 + 命中的片段」会发给模型，原始文件不会。

**Q：可以放多少文件？**
SQLite + FTS5，几万个文件没问题。扫描整盘时建议排除系统目录（已默认排除）。

**Q：怎么彻底删除？**
关闭程序后删除 `data/` 与 `local-secrets/`（分别保存资料索引和密钥）。
