为什么是复制，不是移动

浏览器出于安全限制拿不到你文件的真实磁盘路径，只能读到文件内容 —— 这是 Web 应用的固有语义。所以拖进来的东西被复制到 data/uploads/，原文件完全不受影响。

想让资料长期跟着原文件走，用「添加文件夹」。

多轮追问

「那预算是多少？」这种省略句会自动带上文一起检索，回答下方标注「已结合上文扩展检索」。上下文保留最近 8 轮，检索时取最近 3 轮。

限定范围问答

点左侧资料库里的文件名，或点「限定到某个文件」，接下来的提问只在这一份文件里检索。文件过滤直接下推到 SQL 关联，不是先取全局结果再筛 —— 否则目标文件没进候选池就会被误判成搜不到。全文搜索也会跟着一起收窄，搜索框上方照样能看见范围、照样能取消。

索引体检报告

左侧「体检」按钮打开一份诊断报告：多少文件入库、多少解析失败、按格式怎么分布、哪些还等着索引，外加 OCR、自动同步、API Key 的环境提醒。排查「为什么搜不到」先看它。

导出问答

每条回答下方「导出 Markdown」「导出 Word」，末尾自动附「引用出处」清单（文件名 + 精确位置 + 原文片段）。导出来的东西自带出处，可以直接当交差材料。

再往深处挖一层

会算、会找、记得住 —— 表格里的数直接算出来，资料按目录理清楚，问过的不用重问。

表格聚合计算

问「预算合计是多少」「一共有多少个项目」「支出最多的是哪一项」，直接按表里的原始数值算，不靠模型转述。

目录感知

资料按相对目录分组显示，同名文件不再分不清。点目录标题就能把检索范围限定到那个目录（含它下面的所有子目录），接着问、接着搜都只在这个范围里 —— 目录过滤同样下推到 SQL，目录本身和它的子树一起匹配。

问答历史

每轮问答自动存档到本地，重启工具也不会丢。可以回看、再问一次、导出成 Markdown，也能单条删掉或整体清空。

导入进度与重试

大批量拖入时侧边栏有进度条；某个文件没传成功会单独列出来，可以只重试失败的那几个，不用整批重来。

答案必须能核对

给的是原文片段 + 精确定位，不是摘要。点开引用就能看到当时命中的是哪一段、哪一页、哪一个单元格。

不接模型也能用

工具降级为「原文摘录模式」，界面明确标注「未接入模型，以上为资料原文摘录」，绝不伪装成模型回答。接错 Key 时同样退回摘录模式并附上接口报错原文。

只监听本机

服务固定绑定 127.0.0.1，不对外网暴露。API Key 以明文存在 data/config.json，拷贝目录前记得先删掉它。

只要服务兼容 OpenAI 的 /chat/completions，换个 Base URL 和模型名就能用。

  1. 拿到 API Key

    到服务商平台注册、充值或领赠额，创建 sk- 开头的 Key。

  2. 打开「设置」

    右上角进入，四个字段照抄平台给的地址、Key、模型名。

  3. 测试连接

    点「测试连接」先发一次最小请求，界面显示 ✓ 连接正常 才算通。

  4. 保存设置

    顶栏徽章从「未接入模型」变成「模型：deepseek-chat」，答案卡底部标注「模型生成 · 已标注引用来源」。

两种跑法

同一套后端，源码跑或打包成免安装 exe 都一样。

源码运行

pip install -r requirements.txt 后 python run.py 即可，浏览器自动打开。

--port 9000  换端口
--no-browser 不开浏览器
--rebuild   清库重建

免安装 exe

python tools\build.py 产出目录版 exe，整个目录拷走就能用，首次运行在同级生成 data/。
